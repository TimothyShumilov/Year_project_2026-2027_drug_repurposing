# Данные для EDA

Первоначальный срез `processed/` получен из EMBL-EBI ChEMBL. Сырые ответы API сохраняются локально в `raw/cache/`; запросы, время получения и SHA-256 входят в записи кэша. `raw/manifest.json` фиксирует релиз и полноту пагинации.

Текущий бейзлайн использует подготовленный набор трёх источников в `multisource_v3/`; команды скачивания с Hugging Face и обучения — в [readme.md](../readme.md). Очистку исходного ChEMBL отдельно можно повторить после выполнения `scripts/download_data.py`.

## Источники и разбиение pKi

`processed/` сохраняет исходный ChEMBL и фиксированный тест для 131 мишени. Активные данные находятся в `multisource_v3/`: 242 782 пары pKi и 144 389 структур. В бейзлайне 198 254 пары для 156 мишеней: train — 159 400, validation — 18 640, test — 20 214.

Ответ текущей модели — pKi. Используем три источника: ChEMBL, BindingDB и DrugCentral.

### Критерии выбора датасетов

1. Соответствие задаче: количественные Ki для пары «малая молекула — отдельный человеческий белок». Kd, IC50 и составные оценки не заменяют Ki.
2. Готовность к обучению: есть корректная структура SMILES, однозначный ID белка, точное положительное измерение и известные единицы. Ki переводим в pKi; уже готовое pKi повторно не логарифмируем.
3. Качество и происхождение: можно проследить источник измерения, проверить повторы и противоречия. Копии между базами не считаем дополнительными независимыми примерами.
4. Полезное покрытие после очистки и устранения пересечений. Смотрим на оставшиеся уникальные пары и заполненность частей выборки. Для мишени бейзлайна заранее заданы минимум 300 пар, из них ≥100 train, ≥10 validation и ≥10 test; это пороги мишени, а не размера всей базы.
5. Воспроизводимый открытый доступ: данные можно получить, зафиксировать версию и опубликовать подготовленную выборку на Hugging Face с соблюдением условий источника.

### Используемые источники

В таблице указаны пары после очистки, устранения пересечений и отбора мишеней текущего бейзлайна; проценты рассчитаны внутри источника.

| Источник выбранной метки | Обучение: пар (%) | Validation: пар (%) | Test: пар (%) | Из validation для выбора параметров |
|---|---:|---:|---:|---:|
| [ChEMBL](https://www.ebi.ac.uk/chembl/) | 136 079 (80.4%) | 15 942 (9.4%) | 17 320 (10.2%) | 15 439 |
| [BindingDB](https://www.bindingdb.org/rwd/bind/chemsearch/marvin/Download.jsp) | 20 653 (80.4%) | 2 488 (9.7%) | 2 549 (9.9%) | 0 |
| [DrugCentral](https://www.drugcentral.org/download) | 2 668 (82.8%) | 210 (6.5%) | 345 (10.7%) | 0 |

Train используется для обучения, validation — для выбора настроек или диагностики, test — для итоговой оценки. Гиперпараметры выбираются только по 15 439 исходным validation-парам ChEMBL. Остальные 3 201 validation-пара — диагностика. Разбиение по химическим каркасам общее для всех источников, с целевым соотношением групп 80/10/10; фактические доли строк отличаются из-за разного размера групп.

| Источник | Что делаем перед использованием |
|---|---|
| ChEMBL | Точные положительные Ki в нМ; тест связывания с отдельным человеческим белком, confidence 9, без аннотированной мутации. Пересчёт Ki → pKi. |
| BindingDB | Только Ki из статей и патентов; импорты ChEMBL исключены. Отдельный человеческий белок; последовательность экспериментального белка должна совпадать с участком канонической последовательности UniProt. Пересчёт Ki в нМ → pKi. |
| DrugCentral | Соединение таблицы активностей со структурами SDF по STRUCT_ID; только человеческие мишени, ACT_TYPE=Ki и RELATION="=". ACT_VALUE уже содержит pKi: повторный логарифм не нужен. |

Для всех источников проверяем структуры и вычисляем Morgan fingerprints. Повторы внутри источника объединяем медианой; пары с разбросом более 2 pKi исключаем. При пересечении баз выбираем одну метку: ChEMBL → BindingDB → DrugCentral. Поэтому каждая пара в таблице посчитана один раз. Исходные метки и разбиение ChEMBL сохранены.

| [PDBbind](https://www.pdbbind-plus.org.cn/termofuse) | Не получена выгрузка с разрешением на использование и публикацию подготовленных данных на Hugging Face. |

| [Open Targets](https://platform-docs.opentargets.org/) | Связи мишеней с заболеваниями и биомедицинские доказательства не являются количественными метками Ki для этой регрессии. |
| [ClinicalTrials.gov](https://clinicaltrials.gov/data-api/about-api) | Сведения о клинических исследованиях и вмешательствах не дают требуемые измерения Ki для пар «молекула — белок». |

UniProt используется как справочник для проверки вида и последовательностей белков; дополнительных меток и входных признаков RF из него не получаем. Причины исключения — в [excluded_datasets.json](../results/multisource/excluded_datasets.json).

Машиночитаемые количества и правила: [pki_source_usage.json](../results/multisource/pki_source_usage.json), [CSV](../results/multisource/pki_source_usage.csv). PubChem исключён из наблюдений до повторного объединения меток; заново рассчитаны происхождение, диапазоны расхождений, размеры выборок и предсказания RF. Предыдущие локальные данные в `multisource/` остаются историческим кэшем и не используются текущим бейзлайном.

Текущий набор [опубликован на Hugging Face](https://huggingface.co/datasets/tim-shu/drug-affinity-multisource); точная версия — в [hf_publication.json](../results/multisource/hf_publication.json). Локальный пакет — `output/huggingface/drug-affinity-pki-v3/`. Процесс — в [EDA.ipynb](../EDA.ipynb).

## Поля и их роль

В таблице ниже описаны поля исходного ChEMBL (`processed/`). В объединённом наборе (`multisource_v3/`) числовой ответ называется `label`, тип метки — `endpoint='pKi'`, белок — `target_id` (UniProt); `source` и `sources` описывают происхождение.

Исходная запись — одно измерение взаимодействия молекулы с биологической мишенью. Для обучения отбираем отдельные человеческие белки. После очистки запись в `pairs.parquet` — одна пара структуры и мишени с выбранной меткой pKi; повторы внутри источника объединены медианой. Одна структура может иметь измерения для нескольких белков.

| Поля | Значение и использование |
|---|---|
| `smiles` | Обработанная текстовая запись структуры: атомы, связи, стереохимия. Из неё получаем Morgan fingerprints для леса и планируем строить граф для GNN |
| `pki` | Ответ модели: `9 − log10(Ki в нМ)`; большее значение означает более сильное взаимодействие. Исходные Ki и pChEMBL используются для подготовки метки и проверки качества, а не как входные признаки |
| `target_chembl_id`, `target_name` | Идентификатор и название белка. Выбирают лес или выход многозадачной сети; биологических признаков белка ID не содержит |
| `molecular_weight`, `heavy_atoms` | Масса в Да и число атомов, кроме водорода; описывают размер молекулы |
| `logp`, `tpsa` | Расчётная липофильность и топологическая полярная площадь в Å²; описывают физико-химические свойства |
| `hbd`, `hba` | Число доноров и акцепторов водородной связи |
| `rotatable_bonds`, `rings` | Число вращаемых связей и колец; описывают гибкость и кольцевое строение |
| `compound_id`, `molecule_index` | Идентификатор структуры и её строка в матрице fingerprints; нужны для объединения данных |
| `connectivity`, `scaffold` | Структура без учёта стереохимии и химический каркас; используются для группировки при разбиении |
| `random_split`, `scaffold_split`, `benchmark_target` | Принадлежность к обучению, валидации или тесту и включение мишени в бенчмарк |
| `n_measurements`, `n_assays`, `n_documents` | Число объединённых измерений, тестов и публикаций для пары; аудит повторов |
| `pki_min`, `pki_max`, `repeat_range` | Минимум, максимум и размах pKi повторов; выявление противоречий |
| `first_year`, `last_year`, `fragment_removed` | Годы первой и последней публикации пары и флаг удаления фрагмента соли; аудит происхождения и обработки |

В текущем RF **признаки X — только 2048 Morgan-битов** локальных атомных окружений радиуса 2 с учётом стереохимии; целевая величина y — pKi. Вектор фиксированной длины подходит для леса и кодирует подструктуры. Числовые дескрипторы выше используются для EDA; их добавление к fingerprints можно проверить отдельно. Метаданные эксперимента, ID и результаты измерений на вход не подаются.

Для будущей GNN планируется граф молекулы: атомы с их элементом, зарядом и ароматичностью и связи с их типом и стереохимией. Выходы соответствуют фиксированным мишеням. Последовательности и 3D-структуры белков в текущем наборе признаков отсутствуют.

В исходной выгрузке также есть тип и единицы измерения, знак `=`, `<` или `>`, тип теста, организм, аннотации мишени и мутации, уверенность сопоставления и флаги качества. По ним отбираем сопоставимые корректные измерения. Идентификаторы измерений, тестов и документов связывают исходные записи с аннотациями. Определения — в [документации ChEMBL](https://chembl.gitbook.io/chembl-interface-documentation/frequently-asked-questions/chembl-data-questions).

## Файлы

Подготовленные файлы:

- `pairs.parquet` — уникальные пары структуры и мишени, медианный pKi, статистики повторов, годы и части выборок.
- `molecules.parquet` — стандартизованные структуры, дескрипторы, химические каркасы и неизменные разбиения.
- `fingerprints.npz` — Morgan fingerprints и идентификаторы строк; radius 2, 2048 бит, учёт стереохимии.
- `targets.csv`, `target_components.csv` — аннотации белковых мишеней и соответствия компонентам.
- `structure_audit.parquet` — результаты проверки исходных структур.

Пропуски активности не заполнены: неизвестная активность не считается отсутствующим связыванием. Документы, годы, идентификаторы и величины измерений не входят в признаки модели. Набор поддерживаемых мишеней и критерии отбора зафиксированы до обучения в `config/eda.json`.

В `results/` сохранены воронка очистки, полные описательные статистики, пропуски, противоречивые повторы, размеры разбиений и метрики. `results/manifest.json` позволяет проверить контрольные суммы подготовленного среза и отчёта.

Интегрированные производные таблицы распространяются по CC BY-SA 4.0 с сохранением исходных уведомлений; подробности и лицензии каждого источника находятся в `LICENSES.md` пакета Hugging Face. Изменения: отбор измерений, проверка структур, белков и аннотаций, объединение повторов и источников, расчёт p-шкал и дескрипторов, формирование разбиений.
