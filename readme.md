## О проекте

Проект посвящён прогнозированию аффинности малых молекул к белковым мишеням с помощью нейронной сети. Полученное решение планируется использовать для поиска новых взаимодействий одобренных препаратов и реализовать в виде сервиса.

## План сбора данных и EDA

Этап включает следующие работы:

1. **Отбор источников.** Сравнение доступных датасетов по составу, качеству, покрытию молекул и мишеней и условиям доступа. Определение набора белковых мишеней и критериев включения одобренных препаратов.
2. **Сбор и согласование данных.** Выгрузка из выбранных источников с фиксацией версий и дат; сопоставление структур молекул и идентификаторов белков, сохранение происхождения записей и условий экспериментов.
3. **Очистка и подготовка меток.** Проверка SMILES и белковых последовательностей, обработка пропусков, дубликатов и противоречивых измерений. Выбор целевой величины и правил обработки разных [типов активности](https://chembl.gitbook.io/chembl-interface-documentation/frequently-asked-questions/chembl-data-questions), согласование единиц измерения и обработка пороговых значений `>` и `<`.
4. **Разведочный анализ данных.** Анализ распределений аффинности, свойств молекул и длин белковых последовательностей; оценка числа измерений на молекулу и мишень, покрытия семейств белков и одобренных препаратов.
5. **Подготовка выборок для экспериментов.** Формирование обучающей, валидационной и тестовой выборок с проверкой пересечений измерений, химических каркасов и близких белковых последовательностей. Подготовка сценариев оценки на новых молекулах, новых мишенях и новых парах известных молекул и мишеней.

**Планируемые результаты этапа:** подготовленный датасет с описанием источников и правил обработки, отчёт EDA и зафиксированные разбиения для обучения и оценки моделей.

## Возможные датасеты и источники данных

На этапе отбора будут рассмотрены перечисленные ниже источники. По результатам сравнения будут выбраны данные для обучения и бенчмарков, библиотека одобренных препаратов и источник белковых последовательностей.

### Обучение и бенчмарки

| Источник | Данные | Работа на этапе отбора |
| :--- | :--- | :--- |
| [BindingDB](https://www.bindingdb.org/rwd/bind/chemsearch/marvin/Download.jsp) | Экспериментальные `Kd`, `Ki`, `IC50` и другие показатели; структуры молекул, последовательности и идентификаторы мишеней. | Оценка в качестве основного источника обучающих данных; анализ типов измерений, условий экспериментов и пересечений с ChEMBL и другими базами. |
| [ChEMBL](https://www.ebi.ac.uk/chembl/) | Курируемые данные о биоактивности, молекулах, мишенях и экспериментах. | Сравнение с BindingDB по качеству и покрытию; оценка выборки экспериментов связывания с отдельными белками (`SINGLE PROTEIN`). |
| [DAVIS](https://tdcommons.ai/multi_pred_tasks/dti/#davis) | Измерения `Kd` для ингибиторов киназ и киназных мишеней; данные доступны в [репозитории DeepDTA](https://github.com/hkmztrk/DeepDTA/tree/master/data). | Оценка в качестве бенчмарка для бейзлайна с учётом ограничения набора киназными мишенями. |
| [KIBA](https://tdcommons.ai/multi_pred_tasks/dti/#kiba) | Данные о взаимодействиях с киназами со составным KIBA score, объединяющим информацию из разных типов активности. | Оценка в качестве дополнительного бенчмарка с отдельной целевой шкалой KIBA score. |
| [PDBbind](https://pdbbind-plus.org.cn/) | Структуры комплексов «белок — лиганд» и значения аффинности. Версия 2020 доступна бесплатно после регистрации; новые версии распространяются по подписке. | Оценка доступности и покрытия структурных данных для экспериментов с моделями, использующими 3D-структуры. |
| [PubChem BioAssay](https://pubchem.ncbi.nlm.nih.gov/docs/bioassays) | Результаты биологических тестов: метки активности и, для части экспериментов, количественные показатели. | Проверка наличия подходящих тестов для выбранных мишеней; оценка дополнительных количественных данных и меток для вспомогательной задачи классификации. |
