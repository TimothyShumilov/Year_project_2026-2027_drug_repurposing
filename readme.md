# 🧬 Drug Repurposing

**Нейронная сеть для прогнозирования аффинности малых молекул к белковым мишеням и поиска новых взаимодействий одобренных препаратов**

## О проекте

Проект посвящён прогнозированию аффинности малых молекул к белковым мишеням с помощью нейронной сети. Полученное решение планируется использовать для поиска новых взаимодействий одобренных препаратов и реализовать в виде сервиса.

## План работы

| Этап | Содержание |
| :---: | :--- |
| **1** · Постановка задачи | Знакомство с куратором, постановка и уточнение задачи, план на год. |
| **2** · Бейзлайн | Изучение существующих подходов для решения поставленной задачи и близких по формулировке; реализация бейзлайна. |
| **3** · Улучшение модели | Любое улучшение бейзлайна — реализация более сложного подхода из списка существующих или осуществление собственных идей. |
| **4** · Создание сервиса | Создание сервиса с имплементацией лучшего полученного решения. |
| **5** · Доработка | Доработка задачи: улучшение сервисной части по обратной связи от команды курса по промышленной разработке. |

## Материалы проекта

В репозитории также сохранено предварительное пилотное исследование по перепрофилированию препаратов при болезни Крона. Его описание, методика и инструкции по запуску находятся в [документации пилота](docs/pilot.md).
