## О проекте

Проект посвящён прогнозированию аффинности малых молекул к белковым мишеням с помощью нейронной сети. Полученное решение планируется использовать для поиска новых взаимодействий одобренных препаратов и реализовать в виде сервиса.

## Сбор данных и EDA

На этом этапе планируется:

- Зафиксировать версии источников и дату выгрузки; определить набор белковых мишеней и критерии включения одобренных препаратов с учётом регулятора и даты одобрения.
- Стандартизировать структуры молекул и идентификаторы белков, проверить SMILES и последовательности, обработать пропуски, дубликаты и противоречивые измерения. Сохранить происхождение записей и условия экспериментов.
- Выбрать целевую величину: например, `Kd` с преобразованием в `pKd = −log10(Kd [M])`. Привести единицы измерения к единой системе и отдельно учитывать значения с ограничениями вида `>` и `<`.
- Изучить распределения аффинности, числа измерений на молекулу и мишень, длины белковых последовательностей и свойств молекул; оценить покрытие семейств белков и одобренных препаратов.
- Подготовить разбиения для проверки на новых молекулах и новых белках (cold-drug / cold-target), оценить пересечения химических каркасов и близость последовательностей между выборками. Для поиска новых взаимодействий дополнительно проверить пары известных молекул и мишеней, отсутствовавшие в обучении.

`Kd`, `Ki` и `IC50` характеризуют разные аспекты взаимодействия и зависят от условий эксперимента. Их следует моделировать отдельно либо объединять с явно обоснованной методикой; наличие общего поля `pChEMBL` само по себе не делает измерения взаимозаменяемыми. См. [описание типов активности в ChEMBL](https://chembl.gitbook.io/chembl-interface-documentation/frequently-asked-questions/chembl-data-questions).

## Возможные датасеты и источники данных

Окончательный набор будет выбран после проверки качества, покрытия и условий доступа. Для обучения нужны пары «молекула — белок» с экспериментальными метками; для поиска новых взаимодействий — библиотека одобренных препаратов и представления белковых мишеней.

### Обучение и бенчмарки

| Источник | Что содержит | Применение и особенности |
| :--- | :--- | :--- |
| [BindingDB](https://www.bindingdb.org/rwd/bind/chemsearch/marvin/Download.jsp) | Экспериментальные `Kd`, `Ki`, `IC50` и другие показатели; структуры молекул, последовательности и идентификаторы мишеней. | Кандидат на основной источник обучающих данных. Требует отбора типов измерений, учёта условий эксперимента и удаления дублей. Часть записей импортирована из ChEMBL и других баз. |
| [ChEMBL](https://www.ebi.ac.uk/chembl/) | Курируемые данные о биоактивности, молекулах, мишенях и экспериментах. | Обучение и расширение покрытия. Для задачи связывания нужно отбирать подходящие binding-assays, тип мишени `SINGLE PROTEIN`, надёжное сопоставление с белком и нужный тип активности. |
| [DAVIS](https://tdcommons.ai/multi_pred_tasks/dti/#davis) | Измерения `Kd` для ингибиторов киназ и киназных мишеней. | Компактный бенчмарк для первого бейзлайна; данные также доступны в [репозитории DeepDTA](https://github.com/hkmztrk/DeepDTA/tree/master/data). Ограничен киназами, поэтому не отражает всё разнообразие лекарственных мишеней. |
| [KIBA](https://tdcommons.ai/multi_pred_tasks/dti/#kiba) | Данные о взаимодействиях с киназами со составным KIBA score, объединяющим информацию из разных типов активности. | Бенчмарк для сравнения моделей. KIBA score имеет собственную шкалу и не является `Kd` или `pKd`; его нельзя напрямую смешивать с ними как одну целевую величину. |
| [PDBbind](https://pdbbind-plus.org.cn/) | Экспериментальные структуры комплексов «белок — лиганд» и связанные значения аффинности. | Подходит при переходе к моделям с 3D-структурами. Версия 2020 доступна бесплатно после регистрации; новые версии распространяются по подписке. Выборка ограничена комплексами с известной структурой. |
| [PubChem BioAssay](https://pubchem.ncbi.nlm.nih.gov/docs/bioassays) | Результаты биологических тестов: метки активности и, для части экспериментов, количественные показатели. | Дополнительные данные для отдельных мишеней или вспомогательной задачи классификации. Требуется проверять тип теста: клеточная активность и метка active/inactive не равнозначны аффинности связывания. |

### Одобренные препараты и белковые последовательности

| Источник | Что содержит | Применение и особенности |
| :--- | :--- | :--- |
| [DrugCentral](https://www.drugcentral.org/download) | Списки препаратов, одобренных FDA, EMA и PMDA, структуры молекул и известные взаимодействия с мишенями. | Формирование библиотеки одобренных малых молекул и сопоставление предсказаний с известными связями. Нужно выбрать регулятора, проверить даты и исключить вещества вне принятого определения малой молекулы. |
| [DrugBank](https://go.drugbank.com/academic_research/) | Курируемая информация о препаратах, их статусах и мишенях. | Дополнительный источник для отбора препаратов и известных взаимодействий. Академические выгрузки требуют оформления доступа; использование данных в сервисе и их распространение зависят от [условий лицензии](https://trust.drugbank.com/drugbank-trust-center/drugbank-terms-of-service). |
| [UniProt](https://www.uniprot.org/) | Аминокислотные последовательности, идентификаторы и аннотации белков. | Получение признаков мишеней и согласование записей между источниками. Это справочник белков, а не самостоятельный датасет с метками аффинности. |

**Предлагаемый старт:** проверить бейзлайн на DAVIS, затем сформировать выборку одного типа измерений из BindingDB или ChEMBL. Для поиска новых взаимодействий собрать библиотеку препаратов из DrugCentral и последовательности мишеней из UniProt; KIBA использовать как отдельный бенчмарк, а PDBbind — при выборе структурного подхода.

При объединении баз необходимо проверять общие первоисточники и повторяющиеся измерения, чтобы избежать утечки между обучением и тестом. Отсутствие известной связи «препарат — мишень» не следует считать отрицательной меткой; новые предсказанные связи требуют дальнейшей проверки.
