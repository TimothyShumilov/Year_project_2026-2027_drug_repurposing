## О проекте

Проект посвящён прогнозированию аффинности малых молекул к белковым мишеням с помощью нейронной сети. Полученное решение планируется использовать для поиска новых взаимодействий одобренных препаратов и реализовать в виде сервиса.

## План сбора данных и EDA

Этап включает следующие работы:

1. **Отбор источников.** Сравнение доступных датасетов по составу, качеству, покрытию молекул и мишеней и условиям доступа. Определение набора белковых мишеней и критериев включения одобренных препаратов.
2. **Сбор и согласование данных.** Выгрузка из выбранных источников с фиксацией версий и дат; сопоставление структур молекул и идентификаторов белков, сохранение происхождения записей и условий экспериментов.
3. **Очистка и подготовка меток.** Проверка SMILES и белковых последовательностей, обработка пропусков, дубликатов и противоречивых измерений. Отбор Ki и правил обработки [типов активности](https://chembl.gitbook.io/chembl-interface-documentation/frequently-asked-questions/chembl-data-questions), согласование единиц измерения и обработка пороговых значений `>` и `<`.
4. **Разведочный анализ данных.** Анализ распределений аффинности, свойств молекул и длин белковых последовательностей; оценка числа измерений на молекулу и мишень, покрытия семейств белков и одобренных препаратов.
5. **Подготовка выборок для экспериментов.** Формирование обучающей, валидационной и тестовой выборок с проверкой пересечений измерений, химических каркасов и близких белковых последовательностей. Подготовка сценариев оценки на новых молекулах, новых мишенях и новых парах известных молекул и мишеней.

**Планируемые результаты этапа:** подготовленный датасет с описанием источников и правил обработки, отчёт EDA и зафиксированные разбиения для обучения и оценки моделей.

## Источники текущего бейзлайна

Используем только измерения Ki из четырёх источников. Ответ модели — pKi. В таблице показаны фактические пары бейзлайна после очистки, разрешения пересечений и отбора 156 мишеней; проценты считаются внутри источника.

| Источник выбранной метки | Обучение: пар (%) | Validation: пар (%) | Test: пар (%) | Из validation для выбора параметров |
|---|---:|---:|---:|---:|
| [ChEMBL](https://www.ebi.ac.uk/chembl/) | 136 079 (80.4%) | 15 942 (9.4%) | 17 320 (10.2%) | 15 439 |
| [BindingDB](https://www.bindingdb.org/rwd/bind/chemsearch/marvin/Download.jsp) | 20 653 (80.4%) | 2 488 (9.7%) | 2 549 (9.9%) | 0 |
| [PubChem](https://pubchem.ncbi.nlm.nih.gov/docs/bioassays) | 42 (91.3%) | 0 (0.0%) | 4 (8.7%) | 0 |
| [DrugCentral](https://www.drugcentral.org/download) | 2 668 (82.8%) | 210 (6.5%) | 345 (10.7%) | 0 |

Train используется для обучения деревьев, validation — для выбора настроек или диагностики, test — для итоговой оценки. Параметры леса выбирались только по 15 439 validation-парам исходного ChEMBL. Остальные 3 201 validation-пара — диагностика; у PubChem validation-пар нет. Все четыре источника используют общее разбиение по химическим каркасам с целевым соотношением 80/10/10. Это объясняет отклонение фактических долей строк от целевых.

| Источник | Что делаем перед использованием |
|---|---|
| ChEMBL | Точные положительные Ki в нМ; тест связывания с отдельным человеческим белком, confidence 9, без аннотированной мутации. Пересчёт Ki → pKi. |
| BindingDB | Только Ki из статей и патентов; импорты ChEMBL исключены. Отдельный человеческий белок; последовательность экспериментального белка должна совпадать с участком канонической последовательности UniProt. Пересчёт Ki в нМ → pKi. |
| PubChem | Только количественные Ki из курируемого импорта BindingDB; ID теста проверен напрямую в PubChem. Те же проверки белка, что для BindingDB. Пересчёт Ki в нМ → pKi. |
| DrugCentral | Соединение таблицы активностей со структурами SDF по STRUCT_ID; только человеческие мишени, ACT_TYPE=Ki и RELATION="=". ACT_VALUE уже содержит pKi: повторный логарифм не нужен. |

Для всех источников проверяем структуры и вычисляем Morgan fingerprints; повторы внутри источника объединяем медианой, а разброс более 2 pKi исключаем. При пересечении баз выбираем одну метку: ChEMBL → BindingDB → PubChem → DrugCentral. Поэтому в таблице каждая пара посчитана один раз. UniProt служит справочником для проверки белков; дополнительных меток и входных признаков RF из него не получаем.

Бейзлайн предсказывает pKi по Morgan fingerprints отдельно для каждой мишени. Основная проверка использует новые химические каркасы; случайное разбиение показано для сравнения. Отсутствующие измерения не считаются отрицательными примерами. Это проверка на новых молекулах для известного набора мишеней; перенос на новые белки потребует другой архитектуры.

Исходный срез ChEMBL: 204 676 пар и 120 720 структур; бенчмарк для 131 мишени. MAE леса на новых каркасах — 0,585 pKi, у прогноза среднего — 0,952; на случайном разбиении — 0,498.

После объединения источников доступны 243 218 пар pKi; бенчмарк охватывает 156 мишеней и 198 300 пар. На прежнем тесте из 16 665 пар MAE составила 0,587 против 0,585 прежде: расширение данных само по себе не улучшило результат. Расширенный эксперимент pKi занял 26 секунд. Параметры выбирались по валидации. Полные результаты — в `results/multisource/`.

Данные [опубликованы на Hugging Face](https://huggingface.co/datasets/tim-shu/drug-affinity-multisource): 5 конфигураций pKi с готовыми train/validation/test, признаками, происхождением меток и лицензиями. Версия — `84ef8e6a10d43e52215b157b1960e2a239068aae`; [подтверждение публикации](results/multisource/hf_publication.json) и [проверка публичного скачивания](results/multisource/hf_remote_verification.json). Локальная копия — `output/huggingface/drug-affinity-pki/`.

Воспроизведение с Python 3.12:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/hf download tim-shu/drug-affinity-multisource --repo-type dataset --revision 84ef8e6a10d43e52215b157b1960e2a239068aae --local-dir output/huggingface/drug-affinity-pki
mkdir -p data/multisource
cp output/huggingface/drug-affinity-pki/prepared/*.parquet data/multisource/
cp output/huggingface/drug-affinity-pki/features/fingerprints.npz data/multisource/
.venv/bin/python scripts/run_eda.py
.venv/bin/python scripts/run_multisource.py --stage train
.venv/bin/python scripts/build_notebook.py
.venv/bin/python scripts/execute_notebook.py
.venv/bin/python scripts/verify_results.py
.venv/bin/python scripts/verify_multisource.py
```

Подготовленный срез позволяет повторить анализ без новой выгрузки. Для повторения очистки из исходных ответов сначала запустите `.venv/bin/python scripts/download_data.py`, затем `.venv/bin/python scripts/run_eda.py --stage prepare --force`. Выгрузка из публичного API занимает десятки минут и сохраняется по страницам; повторный запуск использует кэш. Завершённые эксперименты также сохраняются с проверкой хешей входных данных, поэтому расчёт можно продолжить после переноса на сервер.

Версия ChEMBL и дата получения записаны в `results/eda_summary.json`. Исходный срез ChEMBL распространяется по CC BY-SA 3.0; интегрированные производные таблицы — по CC BY-SA 4.0 с сохранением исходных уведомлений. См. `data/README.md` и лицензии пакета.

Расширенный эксперимент из исходных выгрузок:

```bash
.venv/bin/python scripts/download_sources.py bindingdb drugcentral drugcentral_structures
.venv/bin/python scripts/run_multisource.py
.venv/bin/python scripts/build_notebook.py
.venv/bin/python scripts/execute_notebook.py
.venv/bin/python scripts/verify_results.py
.venv/bin/python scripts/verify_multisource.py
```

Сборка пакета отдельно: `.venv/bin/python scripts/run_multisource.py --stage package`. После локального входа `.venv/bin/hf auth login` публикация выполняется командой `.venv/bin/python scripts/run_multisource.py --stage publish`. Сырые скачивания кэшируются; BindingDB проверяется по опубликованной MD5, остальные файлы фиксируются SHA-256. Лицензии и изменения подробно описаны в карточке пакета и `LICENSES.md` рядом с ней.
