# Пилот перепрофилирования препаратов при болезни Крона

Проверка выполнимости проекта на открытых данных Open Targets 26.09, EMBL-EBI ChEMBL 37 и NIH ClinicalTrials.gov. Дата среза — 5 октября 2026 года. Болезнь: `MONDO_0005011` и её подтипы, без переноса родительского IBD и язвенного колита.

Основной результат: готовых аннотаций направления недостаточно для центрального сравнительного эксперимента. Рабочий пул для генетического ранжирования существует; клинический контрольный набор мал, а белковые комплексы и семейства требуют отдельного анализа.

| --- | ---: |
| Мишени с генетическими доказательствами | 909 |
| Исследовательский пул препаратов после исключения известных показаний | 119 |
| Из них со связью через SINGLE PROTEIN | 47 |
| Подходящие лекарственные исследования / с сопоставленным вмешательством | 681 / 452 |

Следующая рекомендуемая тема: **«Объяснимое ранжирование препаратов для перепрофилирования при болезни Крона: вклад генетических и функциональных доказательств и влияние детализации аннотаций мишеней»**. В пилоте рассчитаны три эвристики; ML-модель не обучалась, временная и фармакологическая валидация не выполнялась.

## Открыть результат

- `reports/pilot_report.html` — автономный отчёт с фильтруемой таблицей, методикой и ограничениями.
- `data/processed/summary.json` — все вычисленные показатели.
- `data/processed/candidate_ranking.csv` — исследовательский рейтинг; не рекомендации по применению препаратов.
- `data/processed/clinical_mechanisms.csv` — аннотированные наборы мишеней и действий; не доказательство независимости механизмов или эффективности.
- `data/processed/manifest.json` — SHA-256 входов и результатов.

## Запуск

Команды выполняются из корня проекта. В Git включены код, конфигурация, обработанные результаты и отчёт. Исходные ответы API и кэш (`data/raw/`) остаются локально и исключены из Git из-за объёма: один из файлов превышает лимит GitHub в 100 MiB. Для нового клона сначала выполните загрузку данных. Новый запрос к API может вернуть другой срез; точное воспроизведение приведённых чисел требует исходного локального снимка от 5 октября 2026 года.

Требуется Python 3.9 или новее; все зависимости входят в стандартную библиотеку.

```sh
python3 -u scripts/fetch_pilot.py
python3 scripts/analyze_pilot.py
python3 scripts/render_report.py
python3 -m unittest discover -s tests -v
python3 scripts/verify_pilot.py
```

Первый шаг требует доступа к публичным API. Секреты, ключи доступа, пользовательские аккаунты и дополнительные Python-пакеты не нужны. Контактные данные исследователей, участников и площадок не запрашиваются.

Повторное получение использует сохранённые ответы; это воспроизведение фиксированного среза, а не автоматическое обновление до нового релиза. Для проверки доступности всех использованных запросов без сети:

```sh
python3 scripts/fetch_pilot.py --offline
```

Для повторного расчёта достаточно агрегированных JSON в `data/raw/`: анализ и отчёт не обращаются к API. Кэш в `data/raw/cache/` дополнительно хранит точные запросы, ответы, время получения и хеши.

## Методика

Параметры и критерии находятся в `config/pilot.json`.

1. Одобренный глобальный пул: ChEMBL `max_phase = 4`, объединение солей/форм через `parent_chembl_id`, исключение семейств, где все одобренные записи отозваны. Это прокси аннотации ChEMBL, а не регуляторная экспертиза.
2. Drug–target-связи: курируемые механизмы ChEMBL, человеческие белковые мишени. UniProt-компоненты сопоставляются с Ensembl-генами Open Targets. Компоненты семейства/комплекса не выдаются за доказанные прямые мишени связывания.
3. Генетические признаки: `gwas_credible_sets`, `gene_burden`, `eva`, `genomics_england`; функциональный признак: score `expression_atlas`. Исключены клинические, литературные и онкологические источники. Общий Open Targets score не используется для ранжирования.
4. Направление: только полные неклинические пары `LoF/GoF` × `risk/protective` и распознаваемые action_type ChEMBL. `OTHER`, `MODULATOR`, неизвестные поля и конфликты не заполняются предположениями. Экспрессия не задаёт направление.
5. Известные показания болезни Крона: объединение ChEMBL `max_phase_for_ind = 4` для MeSH `D003424` с Open Targets reports `APPROVAL` происхождения `DRUG_LABEL`/`REGULATORY_AGENCY`. Это только метки/исключения, не признаки.
6. ClinicalTrials.gov: явное Crohn-condition, интервенционное исследование, лечебная или не указанная цель, DRUG/BIOLOGICAL, первая публикация до даты среза. Сопоставление по основному названию с приоритетом pref_name, затем по синонимам; ограниченная очистка дозировки/пути введения. Placebo и неоднозначные совпадения не учитываются. Комбинации не разбираются догадками. Роль вмешательства и эффективность требуют ручной проверки.
7. Рейтинг — прототип эвристик, без обучения. Веса 0.8/0.2 и множители 1.5/0.5 зафиксированы в конфигурации; они не оптимизированы по клиническому контрольному набору. При равенстве score используется ChEMBL ID. Таблица `drug_target_paths.csv` объясняет вклад каждого пути.

ClinicalTrials.gov отдельно сохраняется как источник проверки, но это не независимый от всей Open Targets экосистемы источник: он также используется в её клинических аннотациях. Разделение обеспечено исключением клинических признаков. Временное разбиение в этом пилоте не выполнено. Неизвестные drug–disease-связи не считаются отрицательными; наличие исследования не считается доказательством эффективности.

## Контроль качества

Пагинация контролируется по общему и уникальному числу записей. Сортировка Open Targets по score при совпадающих значениях может давать повторы на границах страниц; сборщик объединяет проходы с разными размерами страниц до полного уникального покрытия. Идентификаторы релизов Open Targets и ChEMBL сохранены в исходных метаданных и сверяются с отчётом.

Тесты проверяют направление терапевтической гипотезы, сохранение отсутствующей информации и конфликтов, исключение placebo/комбинаций и разграничение Crohn/IBD/UC. Отдельный валидатор сверяет полноту выгрузок, воронки, отсутствие клинических признаков и воспроизводимость результатов.
